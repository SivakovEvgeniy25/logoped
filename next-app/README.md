# Звуковые острова — логопедическая игра

Аркадная веб-игра для пошаговой отработки звукопроизношения у детей 5–10 лет.
Next.js (App Router) + TypeScript + Tailwind CSS + Jest/React Testing Library.

## Идея игры

Звуки русского языка разбиты по **месту образования**:

- 🦔 **Переднеязычные** (Р, Л, С, З, Ш, Ж, Ц, Ч, Щ) — кончик языка у зубов
- 🐦 **Среднеязычные** (Й) — средняя часть языка у нёба
- 🐐 **Заднеязычные** (К, Г, Х) — задняя часть языка у нёба

Для звуков с парой по **твёрдости/мягкости** (Р/Рь, Л/Ль, С/Сь, З/Зь, К/Кь, Г/Гь, Х/Хь)
ребёнок выбирает, что тренировать: твёрдый вариант, мягкий, или оба вместе —
тогда добавляется задание «твёрдый или мягкий?» для различения на слух.

Пошаговый путь: **остров → уровень (звук) → твёрдость/мягкость → 3 мини-игры на слово**
(вставь пропущенный звук → угадай слово по картинке → определи твёрдость, если оба варианта).

## Стек

- **Next.js 16** (App Router, TypeScript, Turbopack)
- **Tailwind CSS 4**
- **Jest + Testing Library** — юнит-тесты игровой логики и smoke-тест компонента
- Прогресс (монеты, звёзды по уровням) сохраняется в `localStorage`
- Конфетти и звуковая обратная связь — на Canvas / Web Audio, без внешних ассетов

## Структура

```
src/
  lib/
    soundData.ts     — данные: группы, звуки, слова, картинки (эмодзи)
    gameLogic.ts      — чистые функции игры (тестируются отдельно от UI)
    progress.ts       — сохранение прогресса в localStorage
    feedback.ts       — звук и конфетти
    __tests__/        — юнит-тесты gameLogic
  hooks/
    useGameState.ts   — состояние игры (экраны, очередь упражнений, прогресс)
  components/
    WorldsScreen, MapScreen, VariantScreen, ExerciseScreen, CompleteScreen, Blobs
    exercises/        — InsertGame, GuessGame, ClassifyGame
    __tests__/        — тест WorldsScreen
  app/
    page.tsx          — сборка экранов, layout.tsx, globals.css
```

## Команды

```bash
npm install       # установка зависимостей
npm run dev       # локальный запуск (http://localhost:3000)
npm run build     # продакшн-сборка
npm run test      # юнит- и компонентные тесты (Jest)
npm run lint      # ESLint
```

## Как расширять

- **Новое слово/звук**: добавьте объект в `GROUPS` в `src/lib/soundData.ts` —
  вся остальная логика (варианты букв, слова-обманки, очередь заданий) подхватит его автоматически.
- **Новый тип мини-игры**: добавьте компонент в `src/components/exercises/`,
  новый `type` в `Exercise` (`src/lib/gameLogic.ts`) и обработку в `ExerciseScreen.tsx`.
