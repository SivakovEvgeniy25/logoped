# Логопед — игры для тренировки звуков

Браузерные HTML-игры для логопедической практики (дети 5–10 лет). Каждый файл самодостаточен — просто откройте в браузере.

## games/

- **sound-islands.html** — «Звуковые острова»: аркадная игра, звуки разбиты на группы по месту образования (переднеязычные, среднеязычные, заднеязычные) с учётом твёрдости/мягкости. Три мини-игры на уровень: вставь пропущенный звук, угадай слово, твёрдый или мягкий.
- **sound-quest.html** — «Звуковая мастерская»: тренировка 5 звуков (Р, Л, Ш, С, З) — вставка звука в слово и угадывание слова по картинке.
- **lighthouse-quest.html** — «Тайна Северного Маяка»: детский квест с загадками (аналог образовательных квестов «Кирилл и Мефодий»).
